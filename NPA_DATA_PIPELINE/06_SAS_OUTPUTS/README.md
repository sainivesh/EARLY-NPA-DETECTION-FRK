# 06_SAS_OUTPUTS - SAS Viya Export Staging Directory

## 1. Directory Purpose

This folder serves as the automated export staging area for datasets generated by the SAS Viya analytical pipeline (`05_SAS_PROGRAMS/`).

When running the SAS programs in SAS Studio or SAS Viya for Learners, the programs export intermediate and final datasets into this folder for verification, audit, and model studio ingestion.

---

## 2. Expected Files in this Directory

| Filename | Producing Program | Row Count | Purpose |
|---|---|---:|---|
| `NPA_MODEL_TRAIN.csv` | `npa_prepare_model_datasets.sas` | 7,000 | Development training population with `npa_flag` and engineered predictors. Ingested into Model Studio for ML model training. |
| `NPA_MODEL_TEST.csv` | `npa_prepare_model_datasets.sas` | 3,000 | Independent development evaluation population with `npa_flag`. Used strictly for out-of-sample champion model testing. |
| `NPA_SCORING_INPUT.csv` | `npa_prepare_model_datasets.sas` | 2,000 | Live scoring population. Contains identical predictor schema to Train/Test, but **completely unlabelled (no `npa_flag`, no future outcome fields)**. |
| `NPA_SCORING_RESULTS.csv` | `npa_postprocess_scores.sas` | 2,000 | Backup copy of the customer-level scored results for the webpage. |
| `NPA_MODEL_TEST_SCORED.csv` | `npa_postprocess_scores.sas` | 3,000 | Backup copy of the scored test set with actual vs. predicted labels. |
| `NPA_MODEL_METRICS.csv` | `npa_postprocess_scores.sas` | 14 metrics | Summary table of test set classification metrics (AUC, KS, Sensitivity, Specificity, Precision, F1, Accuracy). |

---

## 3. Usage Notes

- Ensure the `%let out_dir = &data_dir/06_SAS_OUTPUTS;` macro variable in the SAS programs points to this folder path.
- In SAS Viya for Learners, after running `npa_prepare_model_datasets.sas`, you can download `NPA_MODEL_TRAIN.csv` if you prefer to upload it into Model Studio via the browser interface rather than promoting via CAS.
